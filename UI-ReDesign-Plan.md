## Goal
Unify and enhance the user interface across all screens to provide a consistent and intuitive user experience.

## Design Plan
1. **Research and Analysis**
   - Explore all the screens and find inconsistencies in design elements, color schemes, and typography.
   - Enumerate all common components in order to create new design guidelines.
   - Create an implementation plan for the new design system.
2. **Design System Creation**
   - Develop a comprehensive design system that includes:
     - Color palette
     - Typography guidelines
     - Iconography
     - Component library (buttons, forms, modals, etc.)
   - Ensure accessibility standards are met (contrast ratios, font sizes, etc.).
   - Make the design system easily accessible to all modules.
3. **Implementation**
   - Apply the new design system to all screens, ensuring consistency in layout, spacing, and visual hierarchy.
   - Make sure to avoid scrolling issues and maintain responsive design across different devices.
